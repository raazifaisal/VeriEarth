# VeriEarth System Architecture - Mermaid Diagram

```mermaid
graph TB
    subgraph "Data Sources"
        CSV[CSV Uploads]
        SAP[SAP ERP]
        ORACLE[Oracle Cloud]
        D365[Microsoft D365]
        EO_TILES[EO Tiles: Sentinel-5P, MODIS]
        SENSORS[Ground Sensors]
    end
    
    subgraph "Ingestion & Processing Layer"
        MQ[Message Queue]
        MAP[Header Mapping & Normalization]
        VAL[Validation Engine]
        ETL[ETL Pipeline]
    end
    
    subgraph "Storage Layer"
        PG[(PostgreSQL<br/>+ PostGIS)]
        NEO[(Neo4j<br/>Knowledge Graph)]
        TSDB[(Time Series DB)]
        CACHE[(Redis Cache)]
        OBJ[Object Storage]
    end
    
    subgraph "Core Engines"
        PM[Pattern Mining Engine<br/>GSP/PrefixSpan/SPADE]
        SIM[What-If Simulator<br/>Multi-Objective Optimization]
        ML[ML Pipeline<br/>Trend Prediction]
        FUSION[EO/GIS Fusion Engine]
    end
    
    subgraph "Presentation Layer"
        DASH[SaaS Dashboard]
        API[API Gateway]
        REPORTS[Reports Service]
    end
    
    subgraph "External Integrations"
        ERP_INT[ERP Integration]
        PROC[Procurement Systems]
        REG[Regulatory Systems]
        API_EXT[Third-party APIs]
    end
    
    CSV --> MQ
    SAP --> MQ
    ORACLE --> MQ
    D365 --> MQ
    EO_TILES --> OBJ
    SENSORS --> TSDB
    
    MQ --> MAP
    MAP --> VAL
    VAL --> ETL
    
    ETL --> PG
    ETL --> NEO
    ETL --> CACHE
    
    PG --> FUSION
    OBJ --> FUSION
    TSDB --> FUSION
    FUSION --> CACHE
    
    NEO --> PM
    PG --> PM
    PM --> CACHE
    
    PM --> SIM
    PG --> SIM
    CACHE --> SIM
    
    PG --> ML
    TSDB --> ML
    ML --> CACHE
    
    SIM --> DASH
    SIM --> API
    PM --> DASH
    FUSION --> DASH
    ML --> DASH
    
    API --> ERP_INT
    API --> PROC
    API --> REG
    API --> API_EXT
```
